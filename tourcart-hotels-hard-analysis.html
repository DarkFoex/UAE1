Alco‑first Index

Это не официальный рейтинг отелей. Это модель именно под ваш запрос, где алкоголь весит 45%. Value нормирован внутри этой конкретной подборки, поэтому 10/10 по value = самый дешёвый тур здесь, а не “дешёвый вообще”.

30%качество / бренды

20%пляж
15%цена / value
20%локация + рейтинг

Что не считал: авиакомпанию, багаж, трансфер и страховку — эти параметры не раскрыты одинаково во всех карточках Tourcart на предоставленном snapshot, поэтому сравнивать их было бы выдумкой.
